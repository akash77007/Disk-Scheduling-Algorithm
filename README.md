# 💽 Disk Scheduling Algorithms (OS Lab Assignment-4)

## 📌 Overview
This project implements disk scheduling algorithms to optimize disk head movement and reduce seek time.

## ⚙️ Algorithms Implemented
- FCFS (First Come First Serve)
- SSTF (Shortest Seek Time First)
- SCAN (Elevator Algorithm)
- C-SCAN (Circular SCAN)

## 🎯 Objectives
- Understand disk scheduling concepts  
- Simulate disk head movement  
- Calculate total seek time  
- Compare algorithm efficiency

- Python 3  
- VS Code  
- Linux/Ubuntu
